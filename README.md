# MarketingMirror

Локальный прототип студии перевода: текст → Gemma 4 → английский. Для видео: распознавание речи через Gemini → проверка расшифровки → перевод через Gemma 4.

## Запуск

Нужен Node.js 22.9+ (проверено на Node 24). Сторонних зависимостей нет.

```powershell
Copy-Item .env.example .env
# Впишите в .env ключ GEMINI_API_KEY из Google AI Studio
npm run dev
```

Откройте http://localhost:3000. Интерфейс работает и без ключа; настоящий перевод и распознавание требуют ключа с доступом к моделям. Перезапустите сервер после изменения .env. Не публикуйте ключ и не добавляйте его в frontend.

## Возможности

- Ввод текста, загрузка UTF-8 .txt, пример для быстрого старта.
- Загрузка и перетаскивание MP4 / WebM / MOV до 12 МБ, локальное превью.
- Распознавание речи на исходном языке, редактирование перед переводом.
- Перевод до 12 000 символов с сохранением тона и структуры.
- Копирование и скачивание английского текста.
- Адаптивный русский интерфейс, состояния загрузки и ошибок.

## GitHub Pages

[Демо интерфейса](https://the-fabulous.github.io/MarketingMirror/) публикуется из `main` → `/(root)`. Входная страница — `index.html` в корне; стили и скрипт находятся в `public/` и подключаются относительными путями, чтобы работать внутри `/MarketingMirror/`. Файл `.nojekyll` отключает обработку Jekyll.

GitHub Pages раздаёт статические файлы и не запускает `server.mjs`. В демо доступны ввод текста, загрузка .txt и локальное превью видео. Отправка на AI отключена с пояснением в интерфейсе; фиктивный перевод не показывается. Для настоящего перевода запустите Node.js-сервер по инструкции выше. Публичной версии с AI понадобится отдельный backend с ключом, авторизацией и ограничением запросов. Не помещайте ключ в GitHub Pages или браузерный JavaScript.

## Конфигурация

`GEMINI_API_KEY` — ключ Google AI Studio. `GEMMA_MODEL` — по умолчанию `gemma-4-26b-a4b-it`. `TRANSCRIPTION_MODEL` — по умолчанию `gemini-3.8-flash`. `PORT` — по умолчанию `3000`.

Gemma используется именно для перевода текста. Распознавание видео выполняется отдельной моделью Gemini. Модели можно заменить через .env при изменении доступности API.

## Проверка

```powershell
npm test
```

Тесты используют подставные ответы API: проверяют запросы к моделям, обработку ошибок, усечения ответа, лимиты текста и доступ к HTTP-маршрутам. Реальный AI-запрос без ключа не проверен.

## Границы прототипа

Сервер слушает только 127.0.0.1. Нет аккаунтов, истории, базы данных, обработки длинных видео и очереди задач. Перед публичным развёртыванием нужны авторизация, ограничение частоты запросов и контроль расходов. Файлы не записываются на диск: при запуске распознавания видео передаётся Google, при переводе — текст. Условия хранения у провайдера определяются его настройками и политикой. Ответы AI могут содержать ошибки; проверяйте текст перед публикацией.

API: [Gemma через Gemini API](https://ai.google.dev/gemma/docs/core/gemma_on_gemini_api), [работа с видео](https://ai.google.dev/gemini-api/docs/video-understanding).
